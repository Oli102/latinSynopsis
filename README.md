# Latin Verb Synopsis Practice Tool

An interactive, single-page web application for practicing Latin verb conjugations and synopsis forms. Built with React, TypeScript, and Vite.

## Features

### Core Functionality
- **Interactive Verb Synopsis Table**: Two-column layout showing Active and Passive voices
- **Real-time Validation**: Answers are checked on input with visual feedback
- **Reveal System**: Click the eye button (рџ‘Ѓ) to reveal correct answers with macrons
- **Full Conjugation Coverage**:

  - Modus Imperativus (Singular, Plural)
  - Participia (Present, Perfect, Future)
  - Modus Indicativus (6 tenses: Present, Imperfect, Future, Perfect, Pluperfect, Future Perfect)
  - Modus Coniunctivus (4 tenses: Present, Imperfect, Perfect, Pluperfect)
